# 做T计算器：A股 / 美股

纯静态 GitHub Pages 版本，无需付费域名、后台或 API 密钥。

## 部署
把本文件夹内全部文件上传至 GitHub 仓库根目录。Pages 选择 main 分支、根目录。入口为 index.html，资源使用相对路径。已有 assets 编译文件，部署无需安装 Node。

现有地址：https://2979542747-png.github.io/Intraday-trading-calculator/

本地预览：在本目录运行 `python -m http.server 8765`，浏览器打开 http://localhost:8765。
修改 src 后，用 Node 22.18 或以上运行 `npm install`、`npm run build`。运行 `npm test` 可验证加仓回本核心计算。

## 功能与口径
- 顶部切换 A 股与美股，两者共用同一套布局、卡片、表单、走势图、自选与历史组件；保留各市场独立的费用和数据。
- 正T最低卖出保本价、反T最高买回保本价。反T仅适用于已有持仓，不借券做空；两侧股数相同，每侧按一笔成交估算。
- 手动费用、SEC/TAF 开关、目标盈利反推、持仓成本下降、碎股与价格精度。
- A 股和美股均有“加仓回本计算”：复用原持仓字段、当前行情和各自手续费规则，支持从当前报价上涨百分比或每股上涨金额两种情景。
- 免费参考行情来自东方财富，常规时段分时图以纽约时间显示；可能延迟或不可用，失败时可手动输入价格。
- 自选和历史仅保存在当前浏览器，不上传、不跨设备同步。清除浏览器数据会删除记录。

佣金 = max(股数 × 每股佣金 + 成交额 × 百分比 / 100, 每笔最低佣金)，固定及每股附加费另计。卖出侧 SEC 与 TAF 分项计算。券商佣金默认 0，请按账单设置。监管费预设核对日期 2026-09-18，不自动更新，以最新规则和实际收费为准。
保本价按选定步长保守取整：正T向上、反T向下。不含税务、汇兑和融资利息，不判断账户交易资格。

## 加仓回本计算
入口位于行情区域下方。原持仓成本按既有应用的“每股成本”使用：原总成本 = 原股数 × 已录入每股成本，历史交易费用不另补算。修改此处持仓输入会同步现有做T持仓字段。

本次加仓按整数股、一笔买入计算。目标价按当前同一行情快照加上输入的涨幅或金额计算，不使用开盘价、昨收价，也不强行取整到做T报价步长。实际可成交价格可能不同。

到达目标价后按一笔卖出原持仓与加仓全部股票计算，复用现有 A 股 `calcNetProfit` 和美股 `feesFor` 手续费函数。加仓后每股成本 =（原总成本 + 加仓金额 + 本次买入费）/ 总股数；卖出费只计入目标价清仓净收益。无需加仓时推荐 0 股，不产生买入手续费。

现有费用关于股数非递减，但取整会使净收益局部下降。因此使用基于亏损缺口的整数区间跳过搜索，不对净收益使用二分查找。只跳过已证明无法回本的股数；最终重新调用费用函数验证推荐股数及少一股。

现金流用十进制 BigInt 运算，既有费用函数的数值输出统一至小数点后 10 位消除浮点尾差，再做净额比较，不把小额亏损当作零。系统总股数上限 10 亿股，各项金额上限 100 亿元（或美元），单次最多 10,000 次搜索计算；超过限制明确提示，不返回不可靠推荐。

沿用已有行情刷新，涨幅输入保持不变。免费行情可能延迟；历史行情或刷新失败会标明，行情不存在时不计算。仅为价格情景，不预测、不下单。

## 文件与验证
src/ 为源码，assets/ 为编译资源。A 股入口为 index.html#cn，旧 a-share.html 地址会自动跳转至统一界面。src/a-share-main.js 保留旧版计算源码供费用回归对照，主页面不再加载它。依赖许可证在 assets/app.js.LEGAL.txt。
已验证 972 组价格边界场景，以及正反T、刷新恢复、碎股、费用编辑、自选、手机布局和 A 股切换。
加仓回本另有两种目标模式、零加仓、最低收费、费用舍入、金额精度、无解及越界检查，并与真实 A 股/美股费用函数逐股枚举的 365 个场景交叉验证。

## 统一界面更新
A 股首次进入会读取本机旧费用、自选和历史，迁移至独立的 tcalc_cn_v2 存储；旧记录不删除。美股继续使用 tcalc_us_v1，两市场参数和记录互不混用。A 股保留人民币、北京时间、午间休市时间轴及原费用口径；正反T保本价按所选步长保守取整。买卖参考线可拖动调整价格。

加仓回本提示更新为：“目标涨幅仅用于模拟测算，不代表股价预测或收益承诺。”
